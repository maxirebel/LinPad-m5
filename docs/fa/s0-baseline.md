## ۲. پشتیبان‌گیری (قبل از نصب ۱٫۵٫۱)

1. **پشتیبان داخلی اپ:** `Settings › Maintenance › Backup` → `Create backup`.
   این کار فایل‌سیستم مهمان، تنظیمات دسکتاپ و اسناد باز را در یک آرشیو نگه می‌دارد.
2. **فایل‌های مهم:** هر چیزی که در `/root` یا `~/Documents` ساخته‌ای را با
   `Files` به یک پوشهٔ امن (مثلاً iCloud Drive) کپی کن.
3. **فهرست تنظیمات:** از `Settings › Desktop` و `Settings › Fast Mode` اسکرین‌شات بگیر
   (مقدار Code cache و Performance overlay را بعداً باید بازگردانی کنیم).
4. **محل آرشیو پشتیبان را یادداشت کن** (مسیر داخل مهمان یا فایل خروجی‌گرفته‌شده).

## ۳. نصب ۱٫۵٫۱

1. artifact را از صفحهٔ اجرای `43756327729` دانلود کن (`LinPad-unsigned-ipa`).
2. SHA-256 را بررسی کن: باید `fd93043f…` باشد.
3. با **Sideloadly** نصب کن (iloader روی iOS 27 برای این باندل کار نمی‌کند).
4. اولین اجرا: صبر کن تا لینوکس بالا بیاید و پنجرهٔ **Debian Shelf** را یک‌بار باز کن
   (این کار ابزارهای مهمان را می‌نویسد و پیام `Guest tools installed` را نشان می‌دهد).
5. در `Settings › About` بررسی کن نسخه **1.5.1** باشد.

## ۴. سنجش خط پایه

شرایط یکسان برای همهٔ اجراها: دستگاه خنک، به شارژ وصل، بدون اپ سنگین دیگر،
روشنایی ثابت، هواپیما‌مود برای جلوگیری از sync.

در ترمینال، سه بار با فاصلهٔ یک دقیقه:

```sh
cd /root
sh bench-m5.sh "1.5.1 S0 run1"
sh bench-m5.sh "1.5.1 S0 run2"
sh bench-m5.sh "1.5.1 S0 run3"
```

> اگر `bench-m5.sh` در `/root` نبود، یک clone تازه بگیر:
> `git clone --depth 1 https://github.com/maxirebel/LinPad-m5 /root/src` و سپس
> `cp /root/src/personalize/bench-m5.sh /root/`.

اعداد در `~/linpad-perf/bench.md` ذخیره می‌شوند. میانهٔ سه اجرا **خط پایه** است.

## ۶. بازگشت (Rollback)

1. اپ فعلی را حذف نکن؛ کافی است نسخهٔ ۱٫۴٫۰ را با Sideloadly دوباره نصب کنی
   (همان فایل `…LinPad-unsigned-ipa_2\…ipa`).
2. اگر داده‌ای از دست رفت: `Settings › Maintenance › Backup` → `Restore` از آرشیو مرحلهٔ ۲.
3. اگر آرشیو هم نبود: پروفایل و تنظیمات با اسکریپت‌های `personalize/` قابل بازسازی است
   (`m5-tune.sh --undo`).
