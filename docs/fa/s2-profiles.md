# S2 — سه پروفایل عملکرد

> **اصل حاکم:** هیچ پارامتر JIT یا حافظه‌ای بدون Benchmark واقعی (S3) وارد پروفایل‌ها نمی‌شود.
> پس S2 فقط «سیم‌کشی» است: سه بستهٔ نام‌دار از تنظیماتی که **همین حالا** در Settings وجود دارند.

## پروفایل‌ها

| پروفایل | Code cache (`fastMode.codeCacheMB`) | Performance overlay | نیاز به ری‌استارت |
|---|---|---|---|
| **Balanced** (پیش‌فرض) | دست‌نخورده (خودکار) | دست‌نخورده | نه |
| **Performance** | ۵۱۲ مگابایت | روشن | بله |
| **Battery Saver** | ۰ = خودکار | خاموش | بله (برای بازگشت از ۵۱۲) |

### چرا Battery Saver کش را «کوچک» نمی‌کند

کوچک‌کردن کش کد، کار CPU را **بیشتر** می‌کند (هر برنامه دوباره ترجمه می‌شود) و باتری را
بدتر می‌کند. پس Battery Saver کش را روی «خودکار» می‌گذارد و به‌جایش نمایش‌های اضافی
(overlay) را خاموش می‌کند. کاهش واقعی مصرف در S3 با سنجش بیداری‌ها و انیمیشن‌ها ادامه می‌یابد.

### چرا `ISH_JIT_PCACHE_MB` هنوز در پروفایل نیست

کش ترجمهٔ دائمی روی iOS پیش‌فرض ۴۸ مگابایت است (`jit/pcache.c:156`) و هیچ کلید UI ندارد.
افزایش آن به ۲۵۶ مگابایت **معقول ولی اندازه‌گیری‌نشده** است؛ طبق قانون پروژه، تا S3
وارد هیچ پروفایلی نمی‌شود. اگر S3 آن را تأیید کرد، تنها یک مقدار در
`PerformanceProfile.swift` عوض می‌شود و کلید جدید `fastMode.pcacheMB` اضافه می‌گردد.

## فایل‌های تغییر‌یافته

| فایل | تغییر |
|---|---|
| `Core/System/PerformanceProfile.swift` | **جدید** — enum سه‌حالته + نگاشت + `apply()` + خواندن/نوشتن در UserDefaults |
| `Apps/SettingsApp.swift` | بخش «Performance profile» با Picker و توضیح، کنار Fast Mode |

هیچ تغییری در `AppDelegate.m`، `jit/` یا مقادیر پیش‌فرض انجام نشده است؛ یعنی کسی که
پروفایل را دست نزند، **دقیقاً همان رفتار قبل** را می‌گیرد.

## تست پذیرش

1. `Settings › Performance profile` سه گزینه دارد و انتخاب هر کدام در `Fast Mode › Code cache`
   و `Desktop › Performance overlay` قابل مشاهده است.
2. پس از بستن و باز کردن اپ، پروفایل انتخاب‌شده باقی می‌ماند.
3. انتخاب **Balanced** هیچ کلیدی را بازنویسی نمی‌کند (مقدار قبلی دستی حفظ می‌شود).
4. Behavior عادی: بیلد با پیش‌فرض = هیچ تغییری در اعداد S0.

## بازگشت

`git revert` این کامیت. چون هیچ مقدار پیش‌فرضی عوض نشده، بازگشت صرفاً بخش UI را حذف
می‌کند و تنظیمات کاربر دست‌نخورده می‌ماند.
